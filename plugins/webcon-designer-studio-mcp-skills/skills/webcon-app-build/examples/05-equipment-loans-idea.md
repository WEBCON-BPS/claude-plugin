# Idea

Our office lends equipment to employees: laptops, projectors, cameras and similar items. Today we use a spreadsheet, and we often do not know who has which item and when it comes back. Make a simple application for this.

# Setup

Build a new application in a new application group "Demo apps". Make the current user the application administrator. Assign all tasks to the current user, unless your design says something else. Do not change other applications. Names are in English.

# Freedom

You design the solution: processes, steps, paths, fields, rules and links between workflows. Keep it small: at most 2 processes. Show me the design schema and the list of manual tasks before the first write. If I agree, build it.

# Accepted manual tasks

I accept a partial build with at most 5 manual tasks. Prefer a design that the MCP can build. If an element needs a manual task, keep it only when the application does not work without it.
