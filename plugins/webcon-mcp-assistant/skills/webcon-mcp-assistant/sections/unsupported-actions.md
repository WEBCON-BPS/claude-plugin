# Write Operations and Out-of-Scope Requests

- The General MCP server exposes only read-only tools. Some environments add extra WEBCON MCP servers (installed by an administrator) that can act on elements or run other automations.
- If the user's request needs more than reading data - editing, transitions, starting instances, custom automations - and no such server is connected, tell them a process/tool administrator can add one, instead of saying the action is impossible.
