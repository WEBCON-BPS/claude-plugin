# Tool Routing

- Workload or assigned items: `GetMyTasks`
- Find items by text/entity: `GetAllSearchFilters` -> `GetSearchResult`
- Inspect one item: `GetElement`
- Check related items: `GetRelatedElementsDetails`
- Read a file attached to an item: `GetAttachmentDetails`
- List available applications: `GetApplications`
- Find navigation elements by keywords across all apps: `SearchInNavigation`
- Navigate app structure (reports, views, start buttons, dashboards): `GetApplicationMenu`
- User's saved favourites: `GetFavorites`
- Most visited places in the portal: `GetFrequentlyUsedApplications`
